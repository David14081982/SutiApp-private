# Task Architecture Context contract

Antes de modificar, conservar internamente:

```text
TASK ARCHITECTURE CONTEXT
Task:
Domain:
Target screen:
Primary files:
Repository:
Backend:
Tables / columns:
Storage:
Permissions / RLS:
Source of truth:
Tests:
Upstream / downstream:
Potential impact:
Protected boundaries:
Freshness:
Evidence gaps:
```

No mostrarlo rutinariamente. Elevar al usuario únicamente contradicciones, riesgo material, autoridad sin resolver o decisión necesaria.
